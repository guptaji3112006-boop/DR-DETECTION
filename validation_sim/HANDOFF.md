# UI Member Handoff

This document defines the interface and result files generated by the validation simulation that should be consumed by the UI/Dashboard components.

## Consumable Files

All simulation and evaluation results are exported to the `validation_sim/results/` directory.

### 1. Evaluation Results (`results/baseline/` and `results/gated/`)
- `prediction_audit.csv`: The granular per-image predictions.
  - UI should use `inference_status` to determine if a grade was produced.
  - `iqa_status` and `iqa_score` indicate triage status.
  - `predicted_grade` and `raw_confidence` may be empty/null if `inference_status != SUCCESS`. Do not display empty values as `0`.
- `evaluation_metrics.csv`: Aggregated performance metrics (Sensitivity, Specificity, QWK).
  - Contains Confidence Intervals (`sensitivity_ci_lower`, etc.).
  - Missing/undefined metrics (e.g., when division by zero occurs) are exported as the string `"N/A"`. The UI must handle `"N/A"` strings gracefully (e.g., display as `-` or `N/A`).
- `cm_all.png` and `cm_accepted.png`: Confusion matrices to embed in the UI.

### 2. Screening Simulation Results (`results/`)
- `scenario_results.csv`: Contains the aggregated means and standard deviations across multiple runs (seeds) for each scenario.
  - Fields like `average_queue_wait_completed_minutes_mean` and `p95_queue_wait_completed_minutes_mean` are critical for the workflow dashboard.
- `patient_records.csv`: Raw timeline for every simulated patient (useful for scatter plots or histograms).
- `scenario_runs.csv`: Raw summary metrics per scenario/seed combination.

## Data Types and Fallbacks
- **Undefined Values**: Metrics that cannot be computed will appear as `"N/A"`. The UI should NOT cast these to `0`.
- **Probabilities**: The `probabilities` column is a string representation of a Python list (e.g., `"[0.1, 0.2, 0.5, 0.1, 0.1]"`).
- **Abstentions (Gated Mode)**: Images rejected by the IQA module in `gated` mode will have an `inference_status` of `SKIPPED_BY_GATE`. Do not assign them a DR grade.
